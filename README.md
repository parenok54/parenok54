### 👨‍💻 About Me

- 🔭 **Current Focus**: Architecting scalable, fault-tolerant services with **Python (FastAPI, Django)** and **TypeScript / Next.js**.
- ⚡ **Real-Time Systems**: Deep expertise in **WebSockets, WebRTC**, and scalable **Redis Pub/Sub** message fan-out across worker processes without requiring sticky sessions.

- 💬 **Open For**: Full-time Software Engineering roles, backend-heavy product teams, and high-impact collaborative projects.
